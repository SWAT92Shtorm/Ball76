# Ball76 — Telegram-бот с ИИ: план внедрения

> Документ-«якорь»: чтобы продолжить работу с любого места, даже после паузы.
> Статус: **план согласован вчерне, реализация не начата**.

---

## 1. Цель

Telegram-бот, работающий с ИИ, который умеет:

- **записывать** игрока на игру;
- **отменять** запись;
- **уведомлять** (напоминания об играх, добор игроков, изменение времени).

Бот обслуживает **личные сообщения** и **группы**. Уведомления в группу — ключевой
сценарий для клуба; ИИ-запись доступна через упоминание `@bot` или команды.

**Ключевой принцип:** ИИ только распознаёт намерение и вызывает строго
определённые инструменты. Вся бизнес-логика и валидация остаются в существующем
REST API — ИИ **никогда не пишет в БД напрямую**.

## 3. Архитектура

```
Telegram ──► Bot (grammY, long polling)
                 │
                 ├──► LLM (Groq, function calling) ─┐
                 │                                  │ вызывает tools
                 ├──► Planner (node-cron)            │
                 │                                   ▼
                 └──► Tools ──► REST API Ball76 (localhost:8080) ──► PostgreSQL
```

### Слои

1. **Telegram-слой** — приём обновлений (long polling), маршрутизация личка/группа.
2. **LLM-слой** — Groq, OpenAI-совместимый протокол, function calling.
3. **Слой инструментов** — 6–7 тонких обёрток над REST API.
4. **Планировщик** — `node-cron` для напоминаний и рассылок.
5. **Связка tg ↔ игрок** — таблица `telegram_links`.

### Провайдер ИИ: Google Gemini (ПРОВЕРЕНО, что доступен из РФ)

**⚠️ Groq ЗАБЛОКИРОВАН для России** (проверено с прода `31.56.211.5`):
- `api.groq.com` → HTTP **403 Forbidden** даже с ключом (гео-блок Cloudflare).
- `console.groq.com` → HTTP 403 — сайт регистрации недоступен.
- Вывод: Groq использовать нельзя.

**✅ Google Gemini — доступен из РФ:**
- `generativelanguage.googleapis.com` → отвечает по существу (`400 "API key not valid"`),
  это **не** блокировка.
- OpenAI-совместимый эндпоинт: `POST /v1beta/openai/chat/completions` — работает.
- `aistudio.google.com` — сайт для получения ключа открывается.
- Бесплатный тир щедрый (~15 req/min, ~1500 req/day для flash-моделей).
- Поддерживает function calling → код бота **менять не нужно**, только `.env`.

Конфиг (`.env`):
```
LLM_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai
LLM_API_KEY=<ключ из aistudio.google.com>
LLM_MODEL=gemini-2.0-flash
```

Клиент [`llm.js`](bot/llm.js:1) использует `${baseUrl}/chat/completions`, поэтому любые
OpenAI-совместимые провайдеры переключаются сменой `.env` без правок кода.

**⚠️ Google Gemini — API доступен, но РЕГИСТРАЦИЯ из РФ заблокирована:**
- `aistudio.google.com` → «Failed to list imported projects: permission denied» —
  Google блокирует аккаунты из РФ.
- Значит получить ключ из РФ нельзя → вариант отпадает.

### Рекомендация: vsegpt.ru (российский агрегатор)

**Почему:**
- Доступен из РФ (`api.vsegpt.ru` → HTTP 200).
- **OpenAI-совместим** → код бота менять не нужно, только `.env`.
- **Есть бесплатные текстовые модели**: `perplexity/latest-small-online`
  (prompt=0, completion=0).
- Дешёвые модели с function calling: `openai/gpt-4.1-nano` (0.015/0.06),
  `openai/gpt-oss-20b` (0.014/0.06), `google/gemini-flash-1.5-8b` (0.015/0.04).
- Оплата российскими картами, регистрация простая.

Конфиг (`.env`) для vsegpt:
```
LLM_BASE_URL=https://api.vsegpt.ru/v1
LLM_API_KEY=<ключ из личного кабинета vsegpt.ru>
LLM_MODEL=openai/gpt-4.1-nano          # дёшево, с function calling
# либо бесплатно: LLM_MODEL=perplexity/latest-small-online
```

Регистрация: [vsegpt.ru/apikeys](https://vsegpt.ru/apikeys).

**Страховка при слабом tool calling:**
1. Модель вызывает функцию.
2. Если ответ не парсится → JSON-режим: `{"intent":"signup","hall":"hall1","date":"..."}`.
3. Если и это не сработало → кнопки `/записаться`, `/отменить`.
4. При `429` → ретрай с задержкой.

## 4. Режимы: личка и группа

| Аспект | Личка | Группа |
|---|---|---|
| Privacy mode | — | **ON** (бот видит только `@bot` и команды) |
| Уведомления | да | **да (основной сценарий)** |
| Запись/отмена | да | да, через `@bot` |
| Подтверждения | да | **уводим в личку**, в группе только итог |
| Лимит Telegram | ~30 msg/сек | **~20 msg/min** |

- Участник обязан **один раз нажать `/start`** у бота в личке — иначе Telegram
  запрещает боту писать первым.
- Хранится список `chat_id` групп-подписчиков для рассылок.
- При Privacy OFF доба́вляется фильтр триггеров (упоминание/ответ/ключевое слово).

## 5. Связка Telegram ↔ игрок

**Путь 1 — deep-link с сайта:**

После записи на сайте — кнопка «Подписаться в Telegram» →
`https://t.me/<bot>?start=link_<player_id>_<name>` → бот на `/start` сохраняет связку.

**Путь 2 — ввод ФИО в боте (реализовано):**

1. Пользователь отправляет боту ФИО (Фамилия Имя Отчество).
2. Бот валидирует формат (3–5 слов, буквы/дефис/апостроф) — то же правило,
   что [`NAME_REGEX`](server.js:261) на сервере.
3. Ищет совпадение в базе (`/api/players`, нормализация: регистр, ё→е).
4. **Если найден** — привязывает telegram_id и отвечает «Привязано».
5. **Если не найден** — предлагает кнопкой добавить нового участника:
   > «Игрока „Иванов Иван Иванович“ нет в базе. Добавить вас? [✅ Да] [✖️ Нет]»
   → `POST /api/players-directory` (валидирует ФИО, не создаёт дубликат) →
   привязывает telegram_id.

Стоп-слова («запиши», «отмени», «четверг» и т.п.) не принимаются за ФИО, чтобы
бот не создавал мусорных игроков из фраз-команд.

### Новая таблица (миграция `002_telegram_links.sql`)

```sql
CREATE TABLE IF NOT EXISTS public.telegram_links (
  telegram_id  bigint PRIMARY KEY,
  player_id    integer REFERENCES public.players(id) ON DELETE CASCADE,
  username     text,
  first_name   text,
  linked_at    timestamp without time zone NOT NULL DEFAULT now()
);

CREATE TABLE IF NOT EXISTS public.telegram_chats (
  chat_id   bigint PRIMARY KEY,
  title     text,
  is_group  boolean NOT NULL DEFAULT false,
  notify    boolean NOT NULL DEFAULT true,
  added_at  timestamp without time zone NOT NULL DEFAULT now()
);
```

## 8.1 Сетевая доступность — ПРОВЕРЕНО (важно!)

Проверка выполнена `curl`/`openssl` с production-сервера `31.56.211.5`.

**Хостинг:** Москва, `AS64439 RocketCloud.ru` → российский провайдер, действуют
блокировки Роскомнадзора.

| Ресурс | Результат | Вывод |
|---|---|---|
| **Groq** `api.groq.com` | HTTP 403 (без ключа), 0.11 с | ✅ **доступен** |
| **Telegram** `api.telegram.org` (DNS) | HTTP 000, таймаут 0/6 | ❌ **заблокирован** |
| Telegram — реальный DNS-адрес `149.154.166.110` | 0/10 | ❌ **заблокирован** |
| Telegram — альтернативный `149.154.167.220` | **19/20** ✅ | ⚠️ обход работает |
| Telegram IPv6 | маршрута нет (0 адресов) | ❌ недоступен |
| Контроль: `github.com`, `google.com` | HTTP 200 | сеть в целом работает |

**Детали:**
- Официальные DNS (Cloudflare DoH и Google DoH) отдают `api.telegram.org` →
  `149.154.166.110`, и **именно этот адрес заблокирован** (0/10).
- Альтернативный адрес `149.154.167.220` (тоже Telegram Bot API — подтверждён
  реальным ответом `{"ok":false,"error_code":401}`) проходит в **19/20** попыток.

**Следствие:** при стандартной конфигурации бот **не заработает** — DNS отдаёт
заблокированный IP. Нужно одно из решений (§8.2).

### Важное уточнение про редирект (проверено)

Корень `https://api.telegram.org/` отвечает `302` и редиректит на
`core.telegram.org` — **а он заблокирован**. Отсюда ложное впечатление
неработоспособности: простое обращение к корню всегда падает.

**Реальные API-пути редиректа НЕ вызывают** и работают стабильно:

| Путь | Результат (из контейнера, пиннинг IP) |
|---|---|
| `/` (корень) | 0/5 — редирект на заблокированный `core.telegram.org` |
| `/bot<token>/getMe` | **5/5** — HTTP 401 (валидный ответ Telegram) |
| `/bot<token>/getUpdates` | **5/5** — HTTP 401 (валидный ответ Telegram) |

**Вывод: бот работает через API-пути.** Проверка на живом контейнере вернула
настоящий ответ Telegram `401 Unauthorized: invalid token specified` — канал
доставки подтверждён. Lock-файл `index.js` запущен, образ собран.

## 8.2 Варианты доступа к Telegram API

| Вариант | Плюсы | Минусы | Оценка |
|---|---|---|---|
| **A. Cloudflare Worker-прокси** (рекомендую) | Бесплатно (100k req/день), бот остаётся на текущем сервере, надёжно | Нужен аккаунт Cloudflare, +1 компонент | ⭐ лучший баланс |
| B. Хостинг бота вне РФ | Прямой доступ к Telegram, Groq тоже | Нужен второй хост (VPS/бесплатный тир), доступ к API Ball76 через публичный HTTPS | ⭐ альтернатива |
| C. Пиннинг рабочего IP + ретраи | Ноль доп. инфраструктуры | Нестабильно: **41/50 (82%)** — каждый 5-й запрос падает; IP может смениться/попасть в блок | ❌ рискованно |

**Замер стабильности варианта C** (50 запросов к `149.154.167.220`):
- Успешно: **41/50 (82%)**, отказов: 9/50.
- При более раннем замере было 19/20 → канал «плавает», фильтрация периодическая.
- Для сравнения, в диапазоне `149.154.160.0/20` рабочий адрес **всего один**
  (`149.154.167.220`), резервных нет.

**Вариант A (выбран по умолчанию):** развернуть Cloudflare Worker
`https://tg-proxy.<account>.workers.dev`, который проксирует запросы на
`https://api.telegram.org`, и указать в боте `TELEGRAM_API_ROOT` на этот воркер.
Официально Telegram Bot API поддерживает подмену API-хоста.

> ⚠️ **Решение по варианту доступа нужно принять до Этапа 1.**

## 14. Риски и решения

| Риск | Решение |
|---|---|
| Нет `telegram_id` → некого записывать | Deep-link `/start` с сайта; обязательный `/start` |
| Ошибка ИИ в дате | Подтверждение перед мутацией; дата показывается явно |
| Лимит Groq 429 | Ретрай + fallback на кнопки |
| Flood-лимит Telegram | Уведомления в личку; задержки при массовых пушах |
| Право на приватность | Уведомления только после явного `/start` |
| Утечка секретов | `.env` вне git, права 600, `<bot>` revoke при инциденте |
| Вытеснение PostgreSQL по памяти | `mem_limit: 256m` на контейнере бота |

## 15. Безопасность

- Токен бота и ключ Groq — **секреты**, только в `.env` на сервере.
- В публичный репозиторий `github.com/SWAT92Shtorm/Ball76` не попадают.
- При компрометации: токен — `/revoke` в @BotFather, ключ — удалить в Groq.
- Админ-эндпоинты (`PATCH /api/player/name`, время игры) бот **не вызывает** без
  явных прав; при необходимости — отдельный `X-Admin-Token`.
